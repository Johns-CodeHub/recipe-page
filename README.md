# RECIPE PAGE
A responsive recipe page built with HTML and CSS.

## Overview
This project is a responsive recipe designed to describe the process taken to make a simple omelette, the ingredients and the nutrition

## Built With
- HTML 5
- CSS3
- Flexbox
- Media Queries

## Activity
- Created the structure with HTML and Design with CSS
- Created responsive layouts for different screen sizes using media queries
